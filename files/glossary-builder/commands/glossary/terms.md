---
description: Разобрать тикеты без фронтовых коммитов
---

Обработай тикеты из `out/tickets-without-commits.json` — бэковые,
исследовательские и прочие, не оставившие следа во фронтовом репозитории.

**Запускай это только после того, как основная очередь пройдена.** Иначе агент
будет привязывать термины к модулям, которых в глоссарии ещё нет, и всё уйдёт
в `terms.md` без привязки.

Порядок:

1. Прочитай `out/tickets-without-commits.json`.
2. Отсортируй по `order` и иди по порядку.
3. На каждый тикет запускай `glossary-orphan-terms` с `run_in_background: false`.
4. Отмечай обработанные через `node scripts/status.mjs --done <KEY>`.

Помни главное ограничение этого агента: он **не создаёт новые карточки модулей**.
Тикет без фронтового кода не может быть основанием для модуля во фронтовом
глоссарии. Если в результате его работы появилась новая карточка — это ошибка,
откати её и запиши вопрос в `_unresolved.md`.

По итогу покажи человеку `docs/glossary/terms.md`, особенно раздел «Расхождения
в терминологии»: он полезен людям не меньше, чем агентам.
