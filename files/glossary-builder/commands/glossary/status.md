---
description: Где мы сейчас и какой тикет следующий
---

Запусти:

```
node scripts/status.mjs
```

Покажи человеку: сколько обработано, сколько осталось, какой тикет следующий и
какие у него файлы-цели.

Если пилотные тикеты ещё не закончились, следующим будет тикет из пилота —
очередь всегда начинается с них.

Не запускай обработку сама по себе: для этого есть `/glossary:next`.
